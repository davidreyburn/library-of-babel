Page check

Opens app/babel-phase1.html and app/babel-atlas.html for real, in frames, and asserts they work — that they boot, that the panels fill, that the keys do something, and that neither threw on the way. Nothing in npm test executes either page. Every browser-side defect this project has had was found by a person looking at it: a ReferenceError that blanked the room sentence while 176 assertions passed, a completion poll that stalled forever in a background tab, an atlas drawing every reading room as a gallery. This is the gate for that class. Like core/conformance.html, it is run by opening it.

The first load on a machine links the prototype's shader, which takes about a minute and a half; after that it is seconds. Both frames stay on screen so a failure can be looked at as well as read.
